# Attribution and redistribution permission

This repository is public. Importing an asset does not grant the right to distribute it.

Before any texture, model, audio or other third-party asset is committed here, retain written authorization from the creator for:
- Public distribution through this GitHub repository and its Releases.
- Inclusion in the Obsidrel Showcase ZIP and compiled Minecraft resource packs.
- Download and use by Minecraft servers running Obsidrel Core, including monetized servers, and delivery to connected players.
- Continued authorized in-server use for copies lawfully downloaded before a contributor's later withdrawal.
- GitHub platform permissions required by public repository terms, including current AI/ML permissions: this must be explicitly accepted by the contributor.

For each approved contribution, record its original creator, content pack, applicable terms, website, and approval reference. The approved file manifest must enumerate the assets and SHA-256 hashes. The signed agreement and correspondence remain private. Do not publish private correspondence or personal details.
