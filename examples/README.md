# Example YAMLs — reference only

These files were previously bundled as active defaults in Obsidrel Core 1.0.0.
They are preserved as first-party configuration references for building a smaller
Showcase without depending on third-party models.

**Not distributed.** The Showcase build script packages only root `resources/`
and `pack/`, never this `examples/` folder. No release or download changes
result from staging these examples here.

Before promoting any file into root `resources/`, validate its mechanics,
inter-resource dependencies (Ruby items, armor, loot, actions, conditions,
cooldowns, triggers, recipes, variables and cosmetics) and in-game visuals.
Some visuals use vanilla placeholders, not authored models.

The disabled `ui/menus/visual-example.yml` is a configuration reference for
a non-included DiamondGUI-style image. It does not include or grant rights to
third-party artwork.
